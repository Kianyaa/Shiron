Shiron Privacy Policy

Last updated: 19 November 2026

Shiron is a Discord bot that tracks Counter-Strike 2 game servers and posts map changes and alerts. This page explains what data Shiron stores, why, and how to delete it. Shiron is open source, so you can check everything here in its code.

What Shiron stores

  • Tracked servers, set up by server admins: the Discord server ID, the channel ID for posts, the game server address (and the IP it resolves to), its name, the last map seen, and the settings chosen in /servers list.
  • Map alerts you create with /notify or 🔔 Notify me: your Discord user ID, the Discord server ID, the game server (or "all servers"), and the map name or pattern.
  • Your delivery choice: your Discord user ID and whether alerts reach you by DM or by a mention in the channel.
  • Map pictures and Workshop collections that admins add: the Discord server ID, the map name and the link.

Shiron does not read or store message content, does not collect email addresses, IP addresses of Discord users, or payment information, and does not sell or share data with anyone. It only asks Discord for the Guilds gateway intent.

Temporary data

  • To send DMs quickly, Shiron keeps your DM channel ID in memory. This is gone when the bot restarts.
  • Server logs can contain Discord user, server and channel IDs when something fails (for example a DM that couldn't be sent). Logs are only used to fix problems and are not shared.

Why it's stored

Only to provide Shiron's features: posting map changes, sending the alerts you asked for, and showing the right settings in the panels.

Services Shiron contacts

  • Discord, to receive commands and send messages.
  • The CS2 game servers being tracked, to read their map and player count.
  • Steam Web API and GitHub, to find map pictures. Only map names and collection IDs are sent, never anything about you.

How to delete your data

  • Your alerts and delivery choice: open /notify list and press Remove all. Once you have no alerts left in any server, your saved DM/channel choice is deleted too.
  • A server's data: admins can remove servers in /servers list. When Shiron is removed from a Discord server, everything stored for that server is deleted right away, including its members' alerts there.
  • For anything else, contact us (below) and we'll delete it.

Children

Shiron is meant for people who meet Discord's minimum age. It doesn't knowingly collect anything beyond the Discord IDs described above.

Changes

If this policy changes, the date above is updated and the change is noted in Shiron's changelog (/about).
